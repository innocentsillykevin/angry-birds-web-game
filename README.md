# Angry Birds

这是一个可以离线游玩的三关弹弓小游戏，击中当前关卡的全部绿团子即可过关。

1. 林间小木塔：3 只小鸟，3 个目标。
2. 双塔守卫：4 只小鸟，4 个目标。
3. 森林大堡垒：5 只小鸟，5 个目标。

前两关通过后，点击“下一关”继续挑战；第三关完成后显示“全部通关”，可从第一关再玩。失败时点击“重试本关”，或随时点击“重新开始”重玩当前关卡。

## 直接玩

用 Chrome、Safari 或 Edge 打开 `dist/index.html` 即可。不用安装依赖，也不需要联网。

鼠标或手指按住弹弓上的小鸟，向左后方拖动，松手发射。拉得越远，力度越大，白色圆点显示预计轨迹。等当前小鸟落稳，下一只会自动准备好。点击“重新开始”可以重玩。

想取消这次瞄准时，把小鸟轻轻拖回弹弓附近再松手：小鸟会自动归位，不消耗次数，还可以继续拉动发射。

键盘也可以操作：点击游戏画面后，方向键调整，空格发射，R 重玩。声音默认关闭，可以点击右上角按钮开启。

## 第一个修改实验

用代码编辑器打开 `dist/game-core.js`，找到文件顶部的 `CONFIG`：

- 把 `birds: 3` 改成 `birds: 5`，保存并刷新网页，第一关就有五只鸟了，后两关各多一只。
- 把 `power: 0.19` 改成 `power: 0.23`，小鸟的弹射力度会增大。
- 把 `gravity: 1` 改成 `gravity: 0.7`，小鸟会下落得更慢。

一次只改一个数字，观察效果。不满意就改回去。

## 文件分别做什么

- `dist/index.html`：网页内容、按钮、中文提示。
- `dist/style.css`：颜色、排版、手机适配。
- `dist/game-core.js`：发射、物理碰撞、计分和胜负规则。
- `dist/game.js`：绘画、鼠标、触屏、键盘和音效。
- `dist/vendor/matter.min.js`：Matter.js 0.20.0 物理引擎，MIT 许可证。

所有图形用 Canvas 绘制，音效由浏览器合成，没有外部图片、音频或字体请求。
